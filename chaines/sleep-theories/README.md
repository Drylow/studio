## Ce que contient la sauvegarde autonome

Le paquet du Bureau contient une copie de ce dossier, les fichiers Silo (script,
sources, chapitres, contrôles, kit de chaîne et miniatures), les outils locaux de
scriptwriting, les références et les archives des essais de miniatures, ainsi
qu'un exécuteur technique réutilisable pour les générations via API.
Il contient un manifeste de fichiers avec empreintes SHA-256.

Il ne contient **aucune clé, aucun mot de passe, aucun cookie ni session navigateur**.
Les vidéos MP4 et les projets privés Ultravid n'ont pas été fournis à cette IA.
Le site Ultravid reste un service externe ; son code et ses projets ne sont pas
recréés par ce dossier. L'URL exacte et les identifiants de projets restent à relever.
