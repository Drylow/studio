# Prochain lot : six scripts anglais

Commande utilisateur du 15 octobre 2026 : remplacer la troisième proposition Star Wars par Dune, vérifier les sujets puis écrire les six scripts complets.

Ordre Deep Void Theories : Force, Guilde spatiale, Paul Atréides. Deux sujets Dune pour un sujet Star Wars.
Ordre Quiet Paradox : Silo, FROM, Severance, dans la continuité de la rotation fixée.

État de reprise : les six textes complets sont écrits. Premier passage de relecture effectué sur les 144 chapitres ; corrections locales appliquées et cinq reprises structurelles rédigées par Codex. Une deuxième lecture complète est en cours. Aucun texte n'est encore enregistré comme livré : ne pas importer cette version intermédiaire par erreur.

`script-voix.txt` dans chaque dossier contient le texte assemblé du moment. `chapitres/` contient les éléments qui le composent ; `relecture/` conserve les constats, les versions antérieures et les reprises. `controle-final.json` mesure le texte courant, mais n'est pas à lui seul une validation éditoriale.

Format : anglais parlé, rythme calme, au moins deux heures visées par épisode. La durée sera estimée à partir du nombre de mots puis devra être mesurée sur la voix finale dans Ultravid. Aucun silence ajouté ou boucle pour atteindre la durée.

Limites : Silo télévision uniquement, aucun spoiler des romans ; FROM épisodes diffusés ; Severance épisodes diffusés. Dune : continuité des romans de Frank Herbert annoncée, sans mélanger les adaptations. Force : canon audiovisuel, spéculations explicitement séparées.

Ne lancer ni doublage, ni montage, ni publication depuis ce dossier. Conserver les productions précédentes et leurs miniatures.
