# Covers Crazy Chef 3D

Trois covers regardées et retenues : chef à la spatule, palette crème / vert forêt, outils et aliments de chaque épisode, titres anglais vérifiés. PNG natifs non retouchés, 941 × 1672 pixels (portrait 9:16 avec un demi-pixel d’arrondi sur la largeur).

| Épisode | Cover | Texte |
|---|---|---|
| watermelon | [watermelon-cover.png](watermelon-cover.png) | MELON MAYHEM |
| chocolate | [chocolate-cover.png](chocolate-cover.png) | CHOCO CRUNCH |
| fries | [fries-cover.png](fries-cover.png) | FRY SQUEEZE |

Génération avec l’outil intégré imagegen, un appel par cover. [Prompts exacts et ordre des images envoyées](prompts.md). Les frames de référence ont aussi été conservées sans modification dans `references/`. Le [logo approuvé](../brand/chef-spatula-avatar.png) est réutilisé sans retouche.
