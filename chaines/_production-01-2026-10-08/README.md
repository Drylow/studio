# Five Historical Daily Episodes

User instruction: 20-25 minutes per film, confirmed on 8 October 2026.
Scope: episode 01 for Edo Daily, Aztec Daily, Babylon Daily, Imperial China Daily,
and Ottoman Daily. English narration; no publication or upload is authorized.

Codex writes the scripts, staging, prompts, reference roles, and reviews.
Technical tools only execute the authored instructions. Use the configured CLI
Proxy for images and the configured Algrow voice. Do not use the old rejected Edo
script, voice, or image sequence. Preserve unrelated repository changes.

## Deliverable Gates

1. Research and personally authored narration reviewed against period sources.
2. New narration generated; actual duration between 1,200 and 1,500 seconds.
3. Personally authored shots linked to actual speech, maximum six seconds each.
4. Separate reviewed location masters and stable individual character references.
5. Every generated shot visually reviewed, with corrections where necessary.
6. Final film rendered and decoded; screen captures and audio checked.

At this initial checkpoint there are no completed new full films. Script files
are working production documents, not proof that subsequent gates have passed.
An episode's narration manifest can contain sections before shot authoring;
these are not final shots and must never be sent to montage.
