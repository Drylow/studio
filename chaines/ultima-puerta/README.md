# Última Puerta Segura

Version espagnole (Amérique latine) de Last Safe Door, proposée le 21 oct. 2026.
Même série (Patch, le bunker sous le dépôt de bus), traduite et adaptée épisode par épisode depuis le jour 1.

- `brand/photo_profil_800.jpg` : photo de profil (800×800).
- `brand/banniere_2560x1440.jpg` : bannière au format YouTube ; titre et slogan dans la zone visible sur
  tous les appareils (1546×423 au centre).
- `voces/` : 4 essais de voix sur le même texte (début de l'épisode 1), voix Algrow en espagnol
  d'Amérique latine : Alberto Rodríguez, Fernando Martínez, Juan Carlos, Rada.
