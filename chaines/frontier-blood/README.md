# Frontier Blood (@FrontierBlood)

> « The American frontier, without the Hollywood. »

Chaîne d'histoire dans la lignée de **Dose of History**, sur son créneau le plus vu : la frontière américaine
(Custer, l'Alamo, Fetterman… y font leurs plus gros scores). Format : outil **History Docs**
(`/tools/history-studio`, chaîne `frontier_blood`), script FacelessOS (format `history_doc`), 35-40 min.

## Concept

Les guerres et derniers combats de l'Ouest américain, 1820-1890, racontés minute par minute avec les vrais
chiffres, les armes (portées, rechargement), la faim, la météo, les distances. **Chaque camp a ses sources** :
lettres de soldats et rapports de l'armée à côté des récits de guerriers comanches, lakotas, cheyennes ou
kiowas. Formules de titre du créneau : « They Didn't Just… », « … Was More Terrifying Than You Think »,
« How N Men Held Off M… ».

## Style

- Images : encre et aquarelle (style `ink`), thème parchemin ; miniatures image + 2 lignes de texte posées par
  le code. Idées et images de base : `presets/history_channels/frontier_blood/`.

## Règles

- Faits réels, sources nommées ; chiffres contestés (effectifs, pertes) en fourchette avec qui les avance.
- Respect de tous les peuples : les guerriers autochtones ne sont pas des méchants de film, leurs raisons
  (traités, massacre des bisons) sont dites clairement. Violence dite sobrement.
