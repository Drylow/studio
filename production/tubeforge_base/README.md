# Base distribuable TubeForge

Cette base conserve les modules nécessaires à une installation complète depuis
Git. Les modifications maintenues et le frontend courant sont dans
`../tubeforge_support/`, appliqués par `../tubeforge_workspace.py`.

Installer avec `../tubeforge_setup.py`, depuis la racine du dépôt. Le code est
copié vers `work/TubeForge/` ; aucune donnée privée n'est distribuée ici.
Les IDs de modèles et les clés sont configurés dans les `.env` privés.

Guide complet : [README_SURVIVOR_TUBEFORGE.md](../../README_SURVIVOR_TUBEFORGE.md).
