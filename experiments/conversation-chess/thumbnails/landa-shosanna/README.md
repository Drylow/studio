# Landa / Shosanna — miniature dans le style Sopranos

Une seule composition préparée le 11 octobre 2026 : Landa gauche, Shosanna
 droite, portraits photographiques face à face, café brun sombre, séparation
 blanche mince inclinée, aucun titre incrusté. Le layout reprend celui de
 `../tony-richie-no-e8/badge-layout.json` et la composition de
 `../tommy-alfie-shelby/base-without-badges.png`.

- `Sopranos-style.jpg` : 1672×941, 449061 octets, prêt pour YouTube sous 2 Mo.
- `Sopranos-style.png` : maître sans perte avec les deux SVG originaux.
- `base-without-badges.png` : base conservée pour recomposer les badges.
- `badge-layout.json` : mêmes positions Brilliant gauche / Blunder droite.
- `review.json` : empreintes et revue réelle à pleine taille et à 320 px.

La base est une retouche photographique générée à partir de la composition
 Peaky, du visage du pion Landa validé et d'un vrai photogramme de Shosanna
 (`aunt-ada-passed-away-from-fever-last-spring-1.png`). Les détails des acteurs
 sont reconstruits : ce n'est pas un détourage conservant les pixels du film.
 Landa porte ici une veste et une chemise neutres, Shosanna un cardigan vert ;
 aucun uniforme ni insigne. Les visages sont légèrement plus lisses et Landa
 paraît un peu plus jeune que dans la source.

Les badges ne sont pas générés : le compositeur existant
 `../../compose-thumbnail-badges.mjs` pose les SVG Chess.com exacts `!!` et
 `??`, contrôle leurs empreintes et vérifie l'absence de modification hors
 de leurs rectangles avant encodage. Les sidecars automatiques gardent
 `visually_reviewed:false` ; la revue séparée par deux agents figure dans
 `review.json`. Les yeux sont dégagés, les symboles restent lisibles sur
 téléphone et seules de petites zones de cheveux passent sous les badges.

Aucun upload, envoi Discord ou choix utilisateur n'est déduit de cette revue.
