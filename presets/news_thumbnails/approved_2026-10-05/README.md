# Références des prochaines miniatures sportives

Le 5 octobre 2026, l'utilisateur a validé le rendu des deux miniatures déjà reçues :
« elles sont parfaites », « toutes les prochaines vidéos » dans le même thème.
Il a demandé **d'arrêter les variantes supplémentaires** pour les trois vidéos actuelles.

`reference_01.png` et `reference_02.png` conservent les deux premières propositions
livrées pendant cette série. Utiliser leur rendu comme référence visuelle pour les
prochains sujets : même direction artistique, netteté des portraits, composition,
hiérarchie du texte et contraste. Regarder ces images avant de produire une miniature.
Adapter les personnes et le sujet, puis les couleurs de la chaîne (Cage : bleu clair ;
Pitch : vert). Le choix de l'utilisateur prime sur une mise en page générique.

Les portraits de cette série viennent des sources sous licence conservées dans
`news/*/2026-10-05_*-analysis/thumbnail_credits.json`. Les adaptations doivent conserver
les crédits, liens de licences et obligations de partage à l'identique applicables.
Les textes accrocheurs doivent rester conformes aux faits de la vidéo.

Ne pas lancer de nouvelles variantes pour une miniature déjà approuvée, sauf demande.
