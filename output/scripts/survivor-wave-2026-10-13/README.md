## Production handoff

Create new TubeForge projects with these exact scripts and each saved channel preset. Voice first, using the saved channel voice. Only then author image plans from the real transcript and timestamps.
Use the preset main-character and drawing references. Prepare and inspect actual recurring side-character and location references before generating scenes. Keep the selected background mode and explicit camera-angle variants.
Hard cuts selected for every complete episode. No standalone clip exports for this wave. Rendering and optional future clip ZIP exports run exclusively on VPS, never on the desktop.
Organizer one-click integrations remain deferred. No calendar entries or publication jobs are created by writing these scripts.
Private proxy drafts and source transcripts stay in work/survivor-production-wave-2026-10-13. Public folders contain original narration and continuity/review records only.
